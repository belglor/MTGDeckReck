# Commander

Commander (EDH): 100-card singleton decks — only basic lands may repeat — built
within one legendary commander's color identity.

## Heuristics

Rough counts for a deck; approximate guidance, not targets. Roles overlap (a
card can ramp and fit the theme), and a theme that fills a role frees its slots
for payoffs.

- Lands: ~36–38 — the largest slot in a 100-card deck.
- Ramp: ~10 — Commander's high mana values and long games reward getting ahead on mana.
- Card draw: ~10 — a singleton deck can't lean on duplicate engines to refill.
- Removal / interaction: ~8–10 — a multiplayer board puts more threats on the table to answer.
- Theme cards: the rest, ~25–30 — the payoffs and enablers the request is about.

## Framing

Casual, social, multiplayer. Build for theme and flavour, not competitiveness.
Win rate and meta popularity are never the primary ranking signal — prefer the
on-theme card to the merely strong one.

## Workflow

1. Read the theme: what the deck is about.
2. Cover the roles above; let the theme absorb any role it naturally fills.
3. Within each role, prefer cards that fit the theme over generically strong ones.
